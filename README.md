# Giranak Mobile

Flutter app (Android and iOS) for Giranak.

## Tech Stack

- Flutter, Dart
- Firebase Cloud Messaging for push notifications
- Arabic (RTL) and English (LTR)

## Getting Started

Prerequisites: Flutter SDK, Android Studio.

1. `flutter pub get`
2. `flutter run`

## Checks

- `flutter analyze`
- `flutter test`
